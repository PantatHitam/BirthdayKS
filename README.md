# Birthday Surprise
1. `npm install` lalu `npm run dev` (http://localhost:5173)
2. Tanggal: `BIRTHDAY_DATE` di `src/config.js`. Untuk tes, isi tanggal yang sudah lewat.
3. Nama & semua teks: `src/config.js`.
4. Foto: taruh `photo1.jpg` ... `photo5.jpg` di `public/images/`, caption di `src/config.js`.
5. Lagu: `public/music/birthday-song.mp3`.
6. Deploy: push ke GitHub, import di vercel.com (preset Vite otomatis).
